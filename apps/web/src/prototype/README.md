# TAY-36 frontend prototype

This folder is throwaway exploration for Linear issue TAY-36. The branch
`prototype/TAY-36-frontend` is never merged to `master`.

When Taylor picks an idea, it becomes a normal Linear issue and is built
properly on `master`. Do not lift this folder wholesale.

Included here:

- Made-up sample recipes
- A fake data layer (no API, no database)
- Cooking-mode screens and browser-only session/timer state
- Dev toggles for empty, loading, and error

Library, search, and recipe screens still use the real kitchen components
and Coastal tokens. Existing responsive CSS on those screens is unchanged.
New cooking-mode layout is sized for a 16" MacBook Pro desktop window.
