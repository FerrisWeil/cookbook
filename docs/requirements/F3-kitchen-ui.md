## F3 Kitchen UI

F3.1 Taylor and his wife can open the app.
- F3.1.1 They can open it on a desktop browser. [Proposed]
- F3.1.2 They can open it on an iPhone. [Proposed]

F3.2 The app is an installable responsive web app.
- F3.2.1 The app is a responsive web app. [Proposed]
- F3.2.2 It installs to the home screen from a secure context. [Proposed]
- F3.2.3 v1 does not cache the library. [Proposed]
- F3.2.4 v1 does not serve the library offline. [Proposed]
- F3.2.5 A document that never loads shows the browser error. [Proposed]
- F3.2.6 After a load, a failed read is said in words. [Proposed]
- F3.2.7 Install is not required from the production tailnet address. [Proposed]

F3.3 v1 has three screens.
- F3.3.1 The screens are the recipe list, one recipe, and settings. [Proposed]
- F3.3.2 Settings changes the theme and nothing else. [Proposed]
- F3.3.3 v1 has no search, meal plan, fullscreen reading, Chef panel, or live updates. [Proposed]
- F3.3.4 The list shows each recipe's title and favorite. [Proposed]
- F3.3.5 The recipe screen shows the title, the ingredient lines, the steps in order, and nutrition when a row exists. [Proposed]
- F3.3.6 A rating shows on the recipe when it is set. [Proposed]
- F3.3.7 Amount, unit, and name are not shown. [Proposed]
- F3.3.8 The list includes recipes that are not favorites. [Proposed]

F3.4 Controls float on the screen.
- F3.4.1 Controls use an opaque fill. [Proposed]
- F3.4.2 There is no rail, header bar, or bottom bar. [Proposed]
- F3.4.3 Recipe text is not read through a control. [Proposed]

F3.5 The three screens have an accessibility floor.
- F3.5.1 The three screens meet WCAG 2.2 AA. [Proposed]
- F3.5.2 A primary action target is at least 44 by 44 CSS pixels. [Proposed]
- F3.5.3 Hover is never the only way to reach an action. [Proposed]
- F3.5.4 Zoom is not disabled. [Proposed]
- F3.5.5 When the system asks for less transparency, a control stays opaque. [Proposed]

F3.6 The app has a light theme and a dark theme.
- F3.6.1 Light and dark both exist. [Proposed]
- F3.6.2 The first paint follows the system. [Proposed]
- F3.6.3 The choice is on settings. [Proposed]

F3.7 A write from the phone asks which actor is writing.
- F3.7.1 It does not pick an actor. [Proposed]
- F3.7.2 A phone write may set the favorite and the rating. [Proposed]
- F3.7.3 A phone write does not change the title, the ingredient lines, the steps, the servings, or the nutrition. [Proposed]
- F3.7.4 The phone offers only actors that already exist. [Proposed]
