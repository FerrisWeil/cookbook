# MCP

Category F1. Status: Proposed.

Drawn from the accepted decisions. Each statement stays Proposed until Taylor accepts it.

## F1.1 Read

Status: Proposed.

An authorized caller can read a stored recipe and its nutrition.

### F1.1.1 List

Status: Proposed.

An authorized caller can list stored recipes.

## F1.2 Save

Status: Proposed.

An authorized caller can save a recipe and its nutrition.

### F1.2.1 Nutrition row

Status: Proposed.

A save can set, replace, or clear the single nutrition row.

### F1.2.2 Actor

Status: Proposed.

A save names an actor. There is no default.

## F1.3 Secret

Status: Proposed.

A call without the shared secret is rejected.

### F1.3.1 Liveness

Status: Proposed.

Liveness does not require the secret. The response is status only.
